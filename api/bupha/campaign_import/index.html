Module campaign_import 

Source
Expand description

bupha import campaign — translate a peregrin campaign YAML (the ci-gate fleet shape: a github-webhook node carrying params.repos[], git job nodes with on: push.<repo>.<ref>… topics and a shell inner cmd, github-status nodes carrying the status contexts) into a bupha.yaml fleet config.

Mapping: webhook params.repos[] → repos[] entries (secret_env names pass through; the majority secret becomes trigger.secret_env); each git node → one jobs[] entry (branch from the on: ref, runner.kind = "shell" + the inner cmd, context from the matching github-status node); single-job repos whose context is the default collapse to the implicit repo form (repo-level branch/runner).
