pub fn new( name: &str, account_id: &str, store_id: &str, token_env: &str, base_url: Option<&str>, ) -> Result<Self, DeployError>

Build a target from config values. token_env names the env var holding a Secrets Store Write API token; base_url overrides the API base (tests, gateways).

Construction does no network I/O — push/remove do.

Source

pub fn with_token( name: &str, account_id: &str, store_id: &str, token: &str, base_url: Option<&str>, ) -> Result<Self, DeployError>

Build with an explicit token — the test/embedding path.

base_url must be https:// — a plaintext or attacker URL would receive the API token and every pushed value. Loopback http:// is permitted for tests/mocks.

Source

pub fn sink_name(env: &Env, rref: &Ref) -> String

The sink-side name for (env, rref): {env}_{path}, non-[A-Za-z0-9_] chars → _. Stable and collision-light; e.g. (prod, billing/stripe) → prod_billing_stripe.
