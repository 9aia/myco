tamias_driver_kuda

Module queries 

Source
Expand description

Query implementations — pavo query names mapped onto kuda’s surfaces: kuda-query functions over IndexStore, the committed .kuda/ cards, and drift recomputation (kuda status semantics).

Every query returns a serde_json::Value payload. Failures come back as {"error": "…"} markers — the pavo wire contract treats those as partial degradation, never a crashed view.
