cuora-identity-keyring — the age identity in the platform’s session secret store.

The AGE-SECRET-KEY-… string lives as a keyed secret in the user-session credential store — it unlocks with the login session, so reads need no prompt:

  • Linux/*nix — org.freedesktop.secrets (secret-service: GNOME Keyring, KeePassXC, KDE Wallet’s wrapper) via the synchronous libdbus client — no async runtime.
  • macOS — the login keychain.
  • Windows — Credential Manager (DPAPI).

KeyringIdentity::platform is the availability probe: it fails with IdentityError::Unavailable on a headless box (no session bus, no daemon) and callers fall back to cuora-identity-file — never a crash. Tests drive any keyring-core store through KeyringIdentity::with_store (the mock store needs no daemon).
