Crate cuora_notice 

Source
Expand description

Process-wide UX notices — the cuora: … stderr notes that are not audit events (loose-permission warnings, keyring fallback notes, exporter warnings).

Same contract as the audit wire’s mute: mute holds notices instead of writing; unmute replays them in order once the holding surface releases the terminal. Notices are UX, not wire — they never fail an operation and never carry secret material.

Functions§

mute
Hold notices — a terminal-owning surface calls this before it takes over the tty so nothing writes mid-frame.
note
Emit an cuora:-prefixed notice on stderr — or hold it while muted, replayed by unmute.
unmute
Release the hold and replay everything buffered, in order. Idempotent — safe to call when nothing was muted or held.
