§

Add

Install a ref and record it in tamias.yaml + tamias.lock.

Writes the project manifest (deps:/include:) — run from the project dir, not inside a package’s source dir (a package’s own tamias.yaml is its package manifest).

Fields

§reference: String

The ref to add.

§allow_drivers: bool

Consent to register + run the package’s bundled drivers/. Equivalent: TAMIAS_ALLOW_DRIVERS=1.

§

Sync

Reconcile the cwd project’s dep set against the store — install what’s missing or drifted. Never removes store entries: the store is global, not project-scoped; tamias remove stays the uninstall verb.

By default the spec is the project manifest’s deps: (tamias.yaml + tamias.lock); --from-lock swaps the spec to tamias.lock itself — each entry’s pinned source_ref is installed, the manifest is not consulted, and the lock is never rewritten.

Fields

§locked: bool

Strict mode — every dep must already be current per tamias.lock + the store; drift or a missing lock entry fails the dep instead of installing/moving it.

§from_lock: bool

Install tamias.lock entries verbatim (the lock is the spec) instead of reconciling the manifest’s deps:.

§allow_drivers: bool

Consent to register + run the packages’ bundled drivers/. Equivalent: TAMIAS_ALLOW_DRIVERS=1.

§json: bool

JSON output.

§

Logs

Fields

§lines: u32
