Source
Expand description

tamias — the CLI. P2b: the distribution verbs over the source port, the content-addressed cache, and the local store. PL-008 added the operator surface for the provider model: drivers (discovery + capabilities), provider list (installed provider: blocks), run/logs (foreground exec + journal over provider services), and service/deploy/uninstall for the systemd units they render.
