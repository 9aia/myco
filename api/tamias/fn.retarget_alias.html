pub(crate) fn retarget_alias(
    alias: &Path,
    entry_dir: &Path,
    force: bool,
) -> Result<(), Error>
Expand description

Point alias at entry_dir, replacing a stale link — one symlink rewrite retargets every link the package owns. Unix only: on copy platforms the payload files are copied directly and the alias is bookkeeping for --unlink’s scan, so it’s left absent. force also removes a non-symlink occupant.
