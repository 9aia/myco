tamias-driver-myco — the pavo view driver for a repo’s project/ ledger.

Verbs (the tamias driver contract):

  • manifest — print the [DriverManifest] JSON (discovery probe; never touches project state).
  • capabilities — {"capabilities": ["pavo"], "verbs": […]}.
  • serve — ndjson JSON-RPC on stdio: {"op":"manifest"}, {"op":"views"}, {"op":"view","view":…,"params":{…}}, {"op":"query","query":…,"params":{…}} → {"ok":true,"result":…} / {"ok":false,"error":…}.

Which repo: each view/query resolves its own target — params.dir/params.root → $MYCO_DIR → cwd discovery (see data.rs for the exact order). manifest/views are project-free so pavo can enumerate drivers anywhere.
