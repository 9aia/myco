cuora — secrets broker for agents. Sealed, not spilled.

Code and config carry cuora:// references, never values; cuora run materializes declared secrets as env vars in the child only. Every materialization — and every denial/failure — emits an audit event: ndjson on stderr, plus OTLP spans when OTEL_EXPORTER_OTLP_ENDPOINT is set.

Values never enter via CLI args — put/rotate read stdin or a hidden /dev/tty prompt (args land in shell history and /proc). get is the escape hatch that prints a value to stdout; [guardrails] can advisory-deny it for agents.
