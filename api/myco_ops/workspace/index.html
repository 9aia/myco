Module workspace 

Source
Expand description

The workspace selector (P-016) — [workspace] repos glob patterns in user-layer myco.toml, matched against universe repo names (lasius clones ∪ registry). The workspace is a scope, not a ledger: index-sourced views (org-board, org-status) filter to the resolved set; single-ledger verbs keep using current/discovery.

Read/write policy mirrors crate::current: MYCO_CONFIG may supply the table on reads (it wins), writes always land in the canonical user file via toml_edit, and repo ./myco.toml is never a source.
