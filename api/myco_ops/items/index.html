Item ops — the I/O shell around myco-core’s domain: store open/save, the commit-per-mutation tail, item-file reads, and the shared output verbs. The pure pieces (ledger doc surgery, state walks, compact, tree_view, require_kind, NewItemMeta) live in myco-core and are re-exported here so call sites read items::X either way.

Input bundle for new_file — one per <kind> new call. word is the commit-message noun (chore: new issue I-001).

Optional metadata applied to a freshly-created item — the parsed --pri/--owner/--label/--blocks/--epic/--milestone bundle every add/new front-end shares. Validated on apply.
TaskLoc
Which doc a task lives in — and its position inside. path is the index trail into the section’s item tree: [2] is the third top-level item, [2,0] its first child.
