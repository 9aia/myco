The current-ledger selector (P-015/P-016) — the user-level, mutable “which ledger does myco open” pointer.

Three sources feed discovery, all resolved against the same target vocabulary (repo | org | <universe name> | </abs/path> | name:<repo>):

  • MYCO_LEDGER / MYCO_LEDGER_SCOPE — per-invocation env.
  • [current] in the user-layer myco.toml — mode = always beats cwd discovery, mode = backup answers only when discovery finds nothing. MYCO_CONFIG may read the table (it wins over the user file); writes always land in the canonical user file. Repo ./myco.toml is never consulted — a repo must not pin the user’s ledger.
  • .myco.toml — a per-directory pointer (ledger = "…"), found walking up from cwd, honored only outside git repos (a committed pointer would be repo-controlled injection).

Writes go through toml_edit so comments/formatting survive.
