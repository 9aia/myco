pub fn run(

Expand description

Serve the ndjson loop on reader/writer against the loaded [Ops] — the cuora serve verb’s whole job. Runs until EOF or a shutdown request. A malformed, non-UTF-8, or oversized line is a bad_request response, never a crash and never the end of the loop; only a real stdout/reader I/O failure propagates.
