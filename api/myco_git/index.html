Git plumbing for myco — shells out to the git CLI (the bupha-git/sturn-git convention; no git2/gix). Phase 3 builds init / check / migrate / auto-commit on top of these primitives: the project orphan branch + worktree, and one atomic commit per verb.

Functions§

branch
git branch <name> <start> — create a branch without switching. Pass an empty tree commit for the project orphan, or use checkout --orphan semantics via the CLI layer.
branch_exists
refs/heads/<name> exists.
commit_all
git add -A && git commit --allow-empty -m <msg> — the auto-commit-per-verb path writes files first, then this. --allow-empty keeps no-op verbs honest in the audit trail.
create_orphan_branch
Create name as an orphan branch via plumbing — mktree an empty tree, commit-tree a root commit, update-ref the branch. Unlike git checkout --orphan this never disturbs the index or working tree of the current checkout.
git
Run git -C <repo> <args>; true on exit status 0. stdout is silenced — progress chatter (HEAD is now at …, commit summaries) must never pollute a verb’s --json stream; stderr stays inherited so failures are still diagnosable.
git_out
git -C <repo> <args> → trimmed stdout. stdin is /dev/null — plumbing commands that read stdin (mktree) get an immediate EOF instead of blocking on the caller’s terminal.
has_changes
Uncommitted/untracked changes present (status --porcelain non-empty).
has_commit
True when rev resolves to an object (cat-file -e).
head_commit
git rev-parse --verify HEAD — the commit a worktree/repo is on, None when the branch is unborn. Index freshness is stored head == head_commit(worktree).
is_git_repo
True when start is inside a git work tree.
log
git log newest-first — %H %as %s over a NUL separator so subjects are safe. limit caps the walk (git log -n). An unborn branch yields an empty history, not an error.
main_worktree
The main (first) worktree of the repo dir belongs to — i.e. the repo root when dir is a linked worktree like project/. Derived from --git-common-dir (<main>/.git → <main>).
push_tag

worktree_add_branch

worktree_add_detached

worktree_branch
