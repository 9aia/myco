cuora-testkit — the vault conformance suite.

Every cuora_vault::Vault impl must satisfy the same contract (documented on the trait). vault_conformance! expands into one #[test] per check, each given a fresh vault:

ⓘ
cuora_testkit::vault_conformance!(|| {
    AgeVault::open(&vault_path, x25519::Identity::generate(), &[]).unwrap()
});

Values here are fake by rule — no real secret ever appears in a test fixture.
