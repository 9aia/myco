cuora-identity — the identity port: where the age identity comes from.

The age identity is the master key every vault impl decrypts with (ADR-0001: all stores hold opaque age ciphertext). How that key material is held is a port — same convention as cuora-vault/cuora-config/cuora-deploy:

  • cuora-identity-file — the ~/.config/cuora/identity.txt keyfile (mode 0600); the headless/CI path, overridable via CUORA_IDENTITY_FILE or [vaults.*].identity.
  • cuora-identity-keyring — the platform session secret store (secret-service / Keychain / Credential Manager) via the keyring-core CredentialStore model.

Resolution order (in cuora-ops): an explicit file override wins; else the session keyring is preferred; else the default keyfile. A later arm of this port — a passphrase-wrapped identity file for portable identities — is a new impl, not a new port.
