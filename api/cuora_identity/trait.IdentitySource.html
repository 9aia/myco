Expand description

A source of (and sink for) the agent’s age identity.

Implementations hold raw AGE-SECRET-KEY-… material however their backend prefers; the port speaks parsed [x25519::Identity]s so vault impls never parse text. All methods are sync — no async runtime in the binary.

Required Methods§

Source

fn load(&self) -> Result<Option<Identity>, IdentityError>

Load the stored identity. Ok(None) means this source holds nothing — distinct from an error, so callers can fall through to the next source. Unreadable or corrupt material is Err, never silently None (that would risk clobbering a good identity on store).

Source

fn store(&self, identity: &Identity) -> Result<(), IdentityError>

Persist identity, overwriting any existing entry. Callers wanting no-clobber semantics check load first (see ensure).

Source

fn kind(&self) -> &'static str

Short backend name for messages — "file", "keyring".

Source

fn describe(&self) -> String

Human-facing locator — a keyfile path or a store entry name. Never contains key material.
