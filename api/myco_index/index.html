Index port — the derived, disposable cache that powers myco org views.

Markdown in project/ stays canonical; a RepoSnapshot is a frozen scan of one repo’s ledger keyed by the project-branch HEAD commit it was taken at. Freshness is a one-line check — snapshot.head_commit == git rev-parse HEAD — so callers can rebuild exactly the stale repos. Deleting the whole index is always safe: myco index rebuild derives it back.

Impls: myco-index-redb (~/.local/share/myco/).
