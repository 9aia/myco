cuora-ops — the I/O shell every front-end calls.

cuora-core is pure domain; this crate is everything that touches the outside world: config loading + env/vault resolution (--env/CUORA_ENV → [envs] routing → a concrete cuora_vault::Vault), the env-pin override on refs, the verb operations the CLI calls, and the audit emission — ndjson on stderr plus OTLP span export when OTEL_EXPORTER_OTLP_ENDPOINT is set. cuora (CLI) is a thin clap shell over this; front-ends like cuora-driver (pavo) and cuora-serve call the same functions.
