Module audit

Audit events — the observability wire.

ADR-0001 moved audit ownership to peregrin: no local audit.jsonl. Instead cuora emits ndjson lines on stderr — a peregrin/sepia wrapper can capture them, a human sees a breadcrumb — and, when OTEL_EXPORTER_OTLP_ENDPOINT is set, buffers each event for an OTLP/HTTP JSON span export on flush (see [crate::otel]).

stderr stays the default human wire; CUORA_AUDIT_STDERR=0 silences it (the OTLP-only mode). mute_stderr suspends live stderr writes for surfaces that own the terminal, and unmute_stderr replays the held events afterward, so nothing is lost, just deferred.

Keep the struct small and serializable: it’s the wire contract on both sinks.

Every verb invocation leaves a trail, uniformly:

  • ok — one event per ref materialized or mutated (put/get/rotate/rm, and per-ref inside run/env), or one op-scoped event for ref-less verbs (init/list/check).
  • denied — the op was refused by [guardrails] (advisory).
  • error — the op ran but failed (missing secret, vault error, bad ref).

manifest/schema run before config load — pure introspection, no event. A run child’s non-zero exit is the child’s outcome, not cuora’s — no error event for it.

Functions§

emit
Route one event to the live sinks: stderr ndjson (unless muted or CUORA_AUDIT_STDERR silences it) and the OTLP buffer (when OTEL_EXPORTER_OTLP_ENDPOINT is configured). A broken stderr must never take the broker down — write failures are deliberately swallowed, same for the buffer.
emit_to
Write event as one ndjson line to w — the testable core.
flush
Export every buffered audit event as OTLP spans, then clear the buffer. No-op when OTEL_EXPORTER_OTLP_ENDPOINT is unset or the buffer is empty. Export failures warn once on stderr — audit transport must never fail the op that produced it.
mute_stderr
Suspend live stderr audit writes — for surfaces that own the terminal (an alt-screen UI, for instance). Events keep buffering for OTLP and collect in held for unmute_stderr.
unmute_stderr
Resume stderr writes and replay every event held while muted — call after the terminal is restored so the breadcrumb lands below the UI, not inside it.
