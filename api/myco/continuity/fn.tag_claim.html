The claim-side write behind --session on the claiming verbs (next --claim, item set): apply flags through the shared mutation path and record the claim as a claimed handoff entry tagged with the session — the tag claim_session/interrupt --session read. The item must land (or already sit) in a work state — --session tags a claim, and an open item has none. Caller commits — one commit covers both writes; a failed tag rolls the mutation back. actor names the claimer (falls back to the item’s post-mutation owner, then cli).
