Module continuity 

Source
Expand description

myco handoff / myco resume — the continuity pair. At session end handoff appends a ## <today> · <actor> entry plus note to handoffs/<ID>.md (append-only, one file per item, uniform across kinds). At session start resume emits the minimal restart context — the item, its blocks: dep titles, the latest handoff entries, the open checklist — sized for a prompt, the single-item counterpart of status --prompt.

sepia owns session lifecycle; it calls these verbs from hooks. --session is provenance only: a sepia session id, cli:<pid>, whatever — myco records it, never interprets it.
