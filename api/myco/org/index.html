myco org status|board — cross-repo views over the index.

Every registered repo’s snapshot is checked for freshness (stored head_commit vs the worktree’s current HEAD); a stale or missing snapshot is rebuilt on the spot — org reads never serve old data silently. Repos whose worktree vanished keep their last snapshot and report an error inline.
