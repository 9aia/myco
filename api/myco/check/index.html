myco check [--fix] — validate the ledger and repair drift.

Checks: strict parses (miette-rendered spans), meta.toml counters ≥ max id per kind, duplicate ids across the ledger, dangling blocks: refs, kind/dir filename mismatches, [x]/ status:done items (the rule: done items are deleted — git keeps history), title/frontmatter id mismatches (a file whose title or H1 still carries its old ADR-0008: number), stale PREFIX-NNNN prose references (a mention in a body, title, index or handoff that no live or archived id resolves — code spans/fences and self-references are whitelisted), and non-canonical emit drift.

--fix applies the safe repairs — strip done items, rename misplaced files, renumber title-mismatched items (repointing index links, blocks:/supersedes refs and handoffs), reconcile counters, re-emit canonical — then re-analyzes; without it every finding is just reported.
