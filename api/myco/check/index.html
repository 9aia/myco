myco check [--fix] — validate the ledger and repair drift.

Checks: strict parses (miette-rendered spans), meta.toml counters ≥ max id per kind, duplicate ids across the ledger, dangling blocks: refs, kind/dir filename mismatches, [x]/ status:done items (the rule: done items are deleted — git keeps history), title/frontmatter id mismatches (a file whose title or H1 still carries its old ADR-0008: number), stale PREFIX-NNNN prose references (a mention in a body, title, index or handoff that no live or archived id resolves — code spans/fences and self-references are whitelisted), non-canonical emit drift, and worktree health: a project/ worktree on a detached HEAD, one sitting on a branch that isn’t project, or a branch that was never pushed — the git-side invariants the audit trail depends on.

Two severities (ADR-0002): error findings fail the gate, warning findings are reported and cost nothing. A stale prose reference is a warning, because doc-storage items are deleted when they finish — every handoff and note naming one dangles by design and no fixer can know what the author meant.

--fix applies the safe repairs — strip done items, rename misplaced files, renumber title-mismatched items (repointing index links, blocks:/supersedes refs and handoffs), reconcile counters, reattach a detached worktree, re-emit canonical — then re-analyzes; without it every finding is just reported.

Enums§

Claim 🔒
The id a file claims for itself in prose — frontmatter title and body first-heading both count (ADR-0008: …). One when they agree (or only one speaks), Conflict when they name two different ids of the same kind, None when neither does.
Fix 🔒
A repair --fix applies.
Read 🔒
A file read — Missing only when the path doesn’t exist. Anything else (permissions, non-UTF8) is Unreadable so a file that exists but can’t be read is never reported missing or scaffolded over by --fix.
Severity
How much a finding costs. Error fails the gate; Warn is knowledge for the reader and never changes the exit code — the distinction exists because some findings are by design and unfixable (a prose T-NNN naming an item that was completed and therefore removed: see ADR-0002). A gate that reds on those is a gate everyone learns to ignore.
