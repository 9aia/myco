fn id_ref_tokens(src: &str) -> Vec<(usize, ItemId)>
Expand description

<KIND>-<digits> tokens in prose — a hand-rolled scanner (one pass per file, cheaper than a regex dep for five prefixes). Returns (byte offset, id) pairs; FOO-123, XT-001 and T-001abc don’t tokenize — the prefix needs a word boundary and the digits a trailing one.
