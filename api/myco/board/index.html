Module board 

Source
Expand description

myco board [--md] — kanban of the current repo’s ledger: Backlog | Open | Claimed | In Progress | Blocked columns (done items leave the ledger, so there’s no Done column). Human output is a tabled grid; --md is the same board as a markdown table for embedding in docs; --json is the columns map.

The verb resolves the board named view — a repo’s [views.board] config shadows the built-in preset — and evaluates it through myco_core::eval. The classic status-columns spec keeps the legacy chrome described above; a shadowed spec renders through the generic view renderers.
