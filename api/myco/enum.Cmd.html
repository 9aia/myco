Manifest

Capabilities + protocol version — agent self-discovery.

Schema

The file/state spec, machine-readable JSON Schema.

§

Init

Scaffold project/: orphan branch + worktree + .gitignore + seed files + the managed AGENTS.md agent-awareness block. Idempotent — existing worktree and AGENTS.md prose are preserved, only the marked block is (re)written.

§

Check

Validate schemas + state machine, repair file/index drift; also validates the managed AGENTS.md block on the repo root. Exit 1 with findings; --fix applies safe repairs + commits.

Fields

§fix: bool

Repair drift in place instead of only reporting.

§

Migrate

Convert legacy ledgers to v2: pm/ → project/, or normalize files already on the project branch.

§

Handoff

Attach resumable state at session end — appends a dated entry to handoffs/<ID>.md (any item kind, live or archived; append-only).

Fields

§id: ItemId

Any item id (T-NNN, I-NNN, P-NNN, ADR-NNNN, PL-NNN).

§note: String

Handoff note — done/next/open. - reads stdin.

§actor: Option<Actor>

Who wrote it (devin, human:luis, …; default cli).

§session: Option<String>

Session provenance — a sepia session id, cli:<pid>, any id string.

§

Interrupt

A session ended with work still claimed/in-progress/ blocked — revert the item to open + interrupted handoff, one commit. Session-lifecycle hooks (sepia, CLI session-end) call this; myco never detects sessions itself.

Fields

§id: ItemId

Any item id (T-NNN, I-NNN, P-NNN, ADR-NNNN, PL-NNN).

§note: Option<String>

Extra context appended to the interrupted note.

§actor: Option<Actor>

Who interrupted it (default cli).

§session: Option<String>

Session provenance — a sepia session id, cli:<pid>, any id string.

§

Resume

Minimal context block to restart work on an item — the item, blocks: dep titles, latest handoffs, open checklist. The single-item status --prompt.

Fields

§id: ItemId

Any item id.

§last: Option<usize>

Only the latest N handoff entries (default 10).

§

Status

Cheap digest of the work ledger. --prompt = token-sized.

Fields

§prompt: bool

Render for an agent prompt (minimal tokens).

§

Board

Kanban of the ledger — Backlog | Open | Claimed | In Progress | Blocked. --md emits a markdown table.

Fields

§md: bool

Emit a markdown table (for docs/READMEs).

§all: bool

Show every card — no row cap.

§epic: Option<String>

Only items in this epic.

§milestone: Option<String>

Only items in this milestone.

§

Epic

Items grouped by epic — bare lists epics with counts, a name renders that epic’s board (epic v2 ≡ board --epic v2).

Fields

§name: Option<String>

Epic name — omit for the all-epics summary.

§md: bool

Emit a markdown table (with a name).

§all: bool

Show every card — no row cap (with a name).

§

Milestone

Items grouped by milestone — bare lists milestones with counts, a name renders that milestone’s board.

Fields

§name: Option<String>

Milestone name — omit for the all-milestones summary.

§md: bool

Emit a markdown table (with a name).

§all: bool

Show every card — no row cap (with a name).
