Module view 

Source
Expand description

myco view [NAME] — declarative views (P-006): named presets from [views] config + built-ins, or an ad-hoc spec from flags. One engine: filter → group → sort → limit → format. Read-only — the write path stays item set/todo/issue.

FilterPatch 🔒
The decoded filter flags — each maps onto the same ViewFilter field filter = { … } uses. Shared by view (merged over the named spec’s filter) and next (merged over its open-item default): a set flag replaces that field, unset fields keep the base spec’s value.
Out
Display toggles for the view verb.
RepoRow 🔒
One row of format = "repos" — a repo and its live-ledger counts (None + error when the rescan failed).
SpecPatchCli 🔒
The ad-hoc spec patch — FilterPatch plus the group/sort/limit/format spec fields; with NAME they merge over the named spec (a set field replaces, unset keeps).
