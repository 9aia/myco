Expand description

The ad-hoc spec flags — each maps onto the same ViewSpec fields [views] uses; with NAME they merge over the named spec (a set flag replaces that field, unset fields keep the named spec’s value).

Fields§

§kind: Vec<ItemKind>

Item kinds — task|issue|proposal|adr|plan (repeatable/comma-separated).

§status: Vec<Status>

Statuses — open|claimed|in-progress|blocked|done|deferred (repeatable/comma-separated).

§pri_min: Option<Priority>

Inclusive lower severity bound — low|med|high|crit.

§pri_max: Option<Priority>

Inclusive upper severity bound.

§label: Vec<String>

#-less label — item carries any of these (repeatable/comma-separated).

§owner: Vec<Actor>

Owner actor — item’s owner is any of these (repeatable/comma-separated).

§claimed: bool

Items with an owner.

§unclaimed: bool

Items with no owner.

§epic: Option<String>

Items in this epic.

§milestone: Option<String>

Items in this milestone.

§live_only: bool

Items not superseded by another (ADRs).

§superseded: bool

Items superseded by another (ADRs).

§group_by: Option<GroupAxis>

Group axis — status|priority|kind|owner|epic|milestone.

§sort: Vec<SortKey>

Sort keys — pri,id,-created; - flips a key’s default direction.

§limit: Option<u32>

Keep the first N items after sorting.

§format: Option<ViewFormat>

Renderer — list|board.
