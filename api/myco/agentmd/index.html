Module agentmd

Expand description

The managed AGENTS.md agent-awareness block — init writes it, check validates it, org init rolls it out across registered repos.

The block is marker-delimited so human prose elsewhere in the file survives syncs; a stale or hand-written Agent awareness section is upgraded in place, everything else is untouched.
