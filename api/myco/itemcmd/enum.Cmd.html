Variants§

§

Show

Dump one item — frontmatter fields plus the body for file-backed kinds (--json = the full Item + location + body).

Fields

§id: ItemId

Any item id (T-NNN, I-NNN, P-NNN, ADR-NNNN, PL-NNN) — live or archived.

§

Set

Mutate an item in place. --status is the only field routed through the state machine — single steps only, invalid ones error with the valid targets. Status changes on tasks move the line between TODO.md and BACKLOG.md (done deletes it).

Fields

§id: ItemId

Any item id.

§status: Option<Status>

New status — one legal step from the current one.

§pri: Option<Priority>

Priority: low|med|high|crit.

§owner: Option<Actor>

Owner actor id.

§label: Vec<String>

Add (+x or x) or remove (-x) a label — repeatable.

§unlabel: Vec<String>

Remove a label — repeatable.

§blocks: Vec<String>

Add (+T-1 or T-1) or remove (-T-1) a blocks dep — repeatable.

§unblock: Vec<ItemId>

Remove a blocks dep — repeatable.

§epic: Option<String>

Epic name — "" clears the epic.

§milestone: Option<String>

Milestone name — "" clears the milestone.
