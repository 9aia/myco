myco init — orphan project branch (plumbing, never checkout --orphan), git worktree add project project, canonical scaffold, project/ into the parent .gitignore.

Idempotent: an existing branch is reused, an existing valid worktree gets its scaffold verified/repaired instead of being overwritten.
