Crate myco 

Source
Expand description

myco — project management, grown not built. A mycorrhizal network for your agents: tasks, signals, handoffs.

Agent-first PM: markdown in project/ is canonical and human-editable; every deterministic write goes through this CLI (auto-commit per verb, --json everywhere). The skill teaches agents the verbs; myco manifest/myco schema are the self-describing surface.

Phase 6 wires continuity — handoff/resume over append-only handoffs/<ID>.md files (one per item, any kind); sepia hooks call them at session boundaries. Phase 7 lands the Jira-parity slice — epic:/ms: item metadata + grouping views, absorb importers (comment sweep, Jira CSV, GitHub dumps).

board 🔒
myco board [--md] — kanban of the current repo’s ledger: Backlog | Open | Claimed | In Progress | Blocked columns (done items leave the ledger, so there’s no Done column). Human output is a tabled grid; --md is the same board as a markdown table for embedding in docs; --json is the columns map.
check 🔒
myco check [--fix] — validate the ledger and repair drift.
commit 🔒
myco commit — stage + commit worktree changes with a conventional message. Git identity comes from the repo config, like every other myco commit.
continuity 🔒
myco handoff / myco resume / myco interrupt — the continuity trio. At session end handoff appends a ## <today> · <actor> entry plus note to handoffs/<ID>.md (append-only, one file per item, uniform across kinds). At session start resume emits the minimal restart context — the item, its blocks: dep titles, the latest handoff entries, the open checklist — sized for a prompt, the single-item counterpart of status --prompt. interrupt is the abnormal end: a work-state item (claimed/in-progress/blocked) reverts to open and gets an interrupted handoff in one commit.
digest 🔒
Ledger scans + counts — the shared read path for the view verbs (status, board, report, index rebuild, org).
discover 🔒
Re-export — lives in myco_ops::discover so myco-tui shares it.
group 🔒
myco epic [name] / myco milestone [name] — grouping views over item metadata. Bare lists every group with its live-item count; a name renders that group’s items as the board’s five status columns (epic v2 ≡ board --epic v2).

status 🔒
myco status [--prompt] — the ledger digest; THE agent-context verb. Human output is compact counts + the in-progress and blocked lists; --prompt is a token-sized block (repo, counts one-liner, then items grouped in-progress → blocked → claimed → open-by-priority, one per line, no prose); --json is the structured digest.
templates 🔒
Item-file body templates — embedded format! strings, not a templating engine. Four kinds, four static skeletons; pulling in minijinja + a myco-template crate would add a dependency for nothing these can’t do. Revisit when templates grow variants (epics, milestones).
todo 🔒
myco todo add|done|defer|list — task items in TODO.md.
