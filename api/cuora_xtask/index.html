xtask — repo chores. cargo xtask <verb> via the alias in .cargo/config.toml.

  • check — cargo fmt --check + cargo clippy -D warnings
  • test — cargo nextest run when installed, else cargo test; plus the worker smoke test when bun is installed
  • worker — the worker smoke test: bun test in crates/cuora-vault-cf/worker — executes the REAL index.js over a bun:sqlite D1 shim (the Rust mock can’t catch worker bugs)
  • coverage — cargo llvm-cov (HTML → target/llvm-cov/html); extra args pass through, e.g. --fail-under-lines 100
  • install — release-install cuora into ~/.cargo/bin
  • site — build the docs site (docs/ worktree, VitePress)
