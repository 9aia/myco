Query-language filters (P-058) — a gh-projects-shaped string compiled onto ViewFilter. key:value tokens set filter fields; bare tokens are substring text terms matched by the caller against title/id/labels/repo. Shared by --q/--query on view/next, the TUI / filter, myco ui --view, and the [views.*] filter = "…" config sugar.

Grammar (phase 3 — negation, OR, relative dates):

owner:devin is:open pri:>=high label:bug epic:v2 due:>=today-7d
is:open OR label:bug -owner:bot fix
  • kind:/is: — a status token (open, in-progress, …) or a kind name/prefix (task, T); status wins on overlap.
  • status: — status tokens (repeatable, OR within the field).
  • pri:/priority: — >=p, <=p, >p, <p, or bare p (exact — sets both bounds).
  • label: — #-less label (a leading # is stripped).
  • owner:/assignee: — an actor id; @me/me resolves to the Actor the caller passes in.
  • claimed:/unclaimed — owner-presence (claimed:true, bare claimed, bare unclaimed).
  • epic:/milestone:/cycle: — exact names.
  • due: — YYYY-MM-DD, today/tomorrow/yesterday, Nd/Nw offsets (due:7d, due:-3d), an optional [+-]N[dw] adjust on any date (today-7d), and ordering ops >=/<=/>/</= (due:>=today, due:<2026-12-01) mapping onto due/due_min/due_max. est:/estimate: — points; superseded: — true/false.
  • -term — negation on any token or bare word: -owner:devin compiles onto the filter’s not list, -bug onto the branch’s negated text terms.
  • OR — an uppercase standalone token separates alternatives: each side is a full conjunctive clause (its own key:value terms, text, and - negations). No parenthesization — a b OR c reads (a AND b) OR c.

Repeated tokens merge per field (a set field replaces, like ViewFilter::overlay); ViewSpec::validate invariants (claimed+owner, pri_min > pri_max) surface as parse errors per alternative.
