tamias-driver-cuora — the pavo view driver for cuora.

Verbs (the tamias driver contract):

  • manifest — print the [DriverManifest] JSON (discovery probe; never touches vault state).
  • capabilities — {"capabilities": ["pavo"], "verbs": […]}.
  • serve — ndjson JSON-RPC on stdio: {"op":"manifest"}, {"op":"views"}, {"op":"view","view":…,"params":{…}}, {"op":"query","query":…,"params":{…}} → {"ok":true,"result":…} / {"ok":false,"error":…}.

Target resolution: each view/query builds cuora_ops::Ops from the request params — config/env/actor map to the CLI’s --config/--env/--actor; absent params fall through to $CUORA_CONFIG → ./cuora.toml → ~/.config/cuora/cuora.toml, $CUORA_ENV, $CUORA_ACTOR/$USER — identical to cuora verbs. See data.rs for the secrets-safety contract: this driver renders vault metadata only, never values.
