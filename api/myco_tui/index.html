myco-tui — interactive board TUI for a repo’s project/ worktree.

A thin front-end over myco-ops: every mutation goes through the same ledger ops the CLI verbs use, so writes and commits are identical to myco todo done et al. Ported from pm’s Bubble Tea reference (9aia/pm, docs/tui.md there) — the keymap is vim-style: j/k move, h/l/1/2 boards, Space/dd done, D defer, p promote, Alt+↑/↓ reorder, a add, Enter/esc preview, E $EDITOR, R reload, q quit.
