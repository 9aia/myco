# How to Track Issues

Reside in `project/issues/` (or `issues/`). Filename: `issue-<number>-<short-description>.md`.

## Issue Template
```markdown
# Issue: [Short Summary]

- **Status**: [Open / In Progress / Resolved]
- **Created**: YYYY-MM-DD
- **Description**: What is wrong and steps to reproduce.
- **Checklist**:
  - [ ] Action item 1
  - [ ] Action item 2
- **Resolution**: (Add once resolved, then close/archive the issue)
```
