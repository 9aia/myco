# How to Write & Manage TODOs

Resides in `project/TODO.md`.

## Rules
- **Keep it minimal:** Only keep currently active, pending, and in-progress tasks.
- **Remove completed tasks:** Do **NOT** keep a list of completed items in the file. Remove them entirely once done. Git history maintains the record of completion. This prevents context bloat and saves tokens.
- **Format:** Use simple Markdown bullet points grouped logically by feature/component.
