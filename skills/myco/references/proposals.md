# How to Write & Refine Proposals

Reside in `project/proposals/`. Filename: kebab-case description (e.g., `project/proposals/feature-name.md`).

Follow this structure (based on `project/proposals/realtime_clock_item_frame.md`):

1. **Goal & Overview**: High-level problem statement and final solution goal.
2. **Requirements**: Functional and technical requirements in a list.
3. **Technical Design**: Core classes, API hooks, registries, or draft code/HOCON blocks.
4. **Performance Considerations**: Footprint, update frequencies, event listening safety.
5. **Configuration Options**: Expected config structure.
6. **Multi-Platform Support**: Platform-specific implementation plan.
